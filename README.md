# Казуал Хаб

**Казуал Хаб** — лёгкий сайт для тех, кто любит всё оценивать и иногда доверять выбор случаю. Внутри два инструмента: **оценщик с рейтингом** и **Колесо Казуала** — колесо на выбывание. Никакого бэкенда и сборки: статические страницы, работающие прямо в браузере.

## Что внутри

### Оценки и рейтинги (`/`)

Оценивайте что угодно: игры, фильмы и сериалы, музыку, книги, еду и заведения, аниме и мангу — или создайте свою категорию.

- **Категории и критерии.** Готовые шаблоны с критериями (например, для игр: геймплей, сюжет, графика, звук, атмосфера, реиграбельность, техническое состояние) и возможность собрать свои: названия, описания, порядок, веса критериев.
- **Оценка ползунками от 1 до 10.** К каждому критерию можно добавить заметку, к объекту — фото и описание. Итоговый балл считается автоматически.
- **Рейтинг.** Режимы «Список», «Плитка» и «Тиры» (S/A/B/C/D), сортировка по баллу, новизне и алфавиту, фильтры по уровню («Шедевры 8.5+», «Хорошие 7.5+», «Средние 5–7.4», «Слабые <5»), поиск, избранное, статусы «Завершено» / «Брошено».
- **Сравнение** двух объектов бок о бок и **статистика** по категориям.
- **Журнал изменений:** каждая новая оценка, правка и удаление записываются по датам.
- **Экспорт:** картинка рейтинга (скачать PNG или скопировать), текстовая версия, резервная копия базы в JSON.
- **Профили.** Регистрация/вход или продолжение как гость, аватар, цветные метки авторов; можно переключаться между аккаунтами.
- Светлая и тёмная тема (авто или вручную), адаптивная вёрстка для телефона и десктопа.

### Колесо Казуала (`/koleso/`)

Колесо на выбывание: при каждом спине выпавший сектор вылетает, а последний оставшийся забирает победу.

- Участники добавляются по одному или списком; есть готовые шаблоны.
- **Донаты:** шанс победить равен доле участника в банке. Поддерживаются несколько валют (гривны, доллары, евро, шекели и другие) с пересчётом курсов.
- Настройка длительности спина, размера колеса, режим «Крутить до победителя».
- Гифки для участников и **музыка**: свои треки на спин, вылет и победу; звук можно отключить.
- Экран победителя с возможностью начать новый раунд с теми же участниками.
- Состояние колеса сохраняется между визитами.

## Технологии

- Чистые HTML, CSS и JavaScript — по одному самодостаточному файлу на страницу, без фреймворков и сборки.
- Данные хранятся локально в браузере: `localStorage` (оценки, категории, журнал, профили, настройки) и `IndexedDB` (гифки колеса). Серверной части нет, ничего не уходит на сторону.
- Шрифты [Handjet](https://fonts.google.com/specimen/Handjet) и [Onest](https://fonts.google.com/specimen/Onest) подключаются через Google Fonts.
- Деплой на **Cloudflare Pages** (`wrangler.toml`, SPA-фолбэк в `_redirects`, заголовки безопасности в `_headers`).

## Структура

```
.
├── index.html          # Оценщик и рейтинги
├── koleso/
│   └── index.html      # Колесо Казуала
├── _headers            # Заголовки безопасности (Cloudflare Pages)
├── _redirects          # SPA-фолбэк
└── wrangler.toml       # Конфигурация Cloudflare Pages
```

## Запуск локально

Достаточно открыть `index.html` в браузере. Для полноценной работы (маршруты, `/koleso/`) удобнее поднять любой статический сервер:

```bash
npx serve .
```

## Деплой

```bash
npx wrangler pages deploy .
```

> Все данные живут в браузере пользователя. Чтобы не потерять оценки, периодически скачивайте резервную копию (JSON) из меню.
