# Казуал Хаб

**Казуал Хаб** — лёгкий сайт для тех, кто любит всё оценивать и иногда доверять выбор случаю. На главной два раздела: **Мнение Казуала** (оценки и рейтинги) и **Колесо Казуала** (колесо на выбывание). Без сборки: статические страницы, работающие прямо в браузере, плюс небольшой сервер для друзей.

Сайт: **https://casualhub.pages.dev**

## Что внутри

### Главная (`/`)

Анимированная надпись «Казуал Хаб», карточки разделов с числом оценок, друзей и заявок, лента «Что оценили друзья», вход и регистрация, выбор темы. Между страницами страница сдвигается вбок.

### Мнение Казуала (`/mnenie/`)

Оценивайте что угодно: игры, фильмы и сериалы, музыку, книги, еду и заведения, аниме и мангу — или создайте свою категорию.

- **Категории и критерии.** Готовые шаблоны с критериями (например, для игр: геймплей, сюжет, графика, звук, атмосфера, реиграбельность, техническое состояние) и возможность собрать свои: названия, описания, порядок, веса критериев.
- **Оценка ползунками от 1 до 10.** К каждому критерию можно добавить заметку, к объекту — фото и описание. Итоговый балл считается автоматически.
- **Рейтинг.** Режимы «Список», «Плитка» и «Тиры» (S/A/B/C/D), сортировка по баллу, новизне и алфавиту, фильтры по уровню («Шедевры 8.5+», «Хорошие 7.5+», «Средние 5–7.4», «Слабые <5»), поиск, избранное, статусы «Завершено» / «Брошено».
- **Друзья.** Во вкладке «👤 Мои» переключатель «Я / друзья»: онлайн-аккаунт, заявки в друзья по нику и оценки друзей с разбивкой по критериям. Свои оценки вместе с фото уходят в аккаунт сами после каждого сохранения: друзья видят их с фото, а на другом устройстве после входа всё подтягивается, удалённое пропадает везде.
- **Сравнение** двух объектов бок о бок и **статистика** по категориям.
- **Журнал изменений:** каждая новая оценка, правка и удаление записываются по датам.
- **Экспорт:** картинка рейтинга (скачать PNG или скопировать), текстовая версия, резервная копия базы в JSON.
- **Профили.** Регистрация/вход или продолжение как гость, аватар, цветные метки авторов; можно переключаться между аккаунтами.
- Светлая и тёмная тема (авто или вручную), адаптивная вёрстка для телефона и десктопа.

### Колесо Казуала (`/koleso/`)

Два режима: **на выбывание** (выпавший сектор вылетает, последний оставшийся забирает победу) и **один победитель** (кто выпал с одной прокрутки, тот и победил).

- Участники добавляются по одному или списком; есть готовые шаблоны.
- **Донаты:** шанс победить равен доле участника в банке. Поддерживаются несколько валют (гривны, доллары, евро, шекели и другие) с пересчётом курсов.
- Настройка длительности спина, размера колеса, режим «Крутить до победителя».
- Гифки и стикеры в центре колеса и **музыка**: фоновая и победная, из списка или свой файл; звук можно отключить.
- Анимация победы со случайным стикером, затем карточка победителя: новый раунд, **картинка с итогом** (PNG, на телефоне — «Поделиться») и текст с порядком вылета для чата.
- Состояние колеса сохраняется между визитами.

## Журнал обновлений

«Что нового» хранится в одном файле `whatsnew.html`: его открывает кнопка «Что нового» в шапке главной, Мнения и Колеса (скрипт `whatsnew.js`). Новые записи добавляются сверху. Номер: крупное обновление меняет цифру (1.1.0 → 1.1.1), все мелкие правки одного дня — один патч с буквой (1.1.0b).

## Технологии

- Чистые HTML, CSS и JavaScript — по одному самодостаточному файлу на страницу, без фреймворков и сборки.
- Данные хранятся локально в браузере: `localStorage` (оценки, категории, журнал, профили, настройки) и `IndexedDB` (гифки и музыка колеса).
- Друзья работают через **Cloudflare Pages Functions** и базу **D1**: онлайн-аккаунты (пароли хранятся хешем PBKDF2), заявки и копии оценок, которые видны только друзьям. Без базы сайт работает как раньше, только без друзей.
- Шрифты [Handjet](https://fonts.google.com/specimen/Handjet) и [Onest](https://fonts.google.com/specimen/Onest) подключаются через Google Fonts.
- Деплой на **Cloudflare Pages** (`wrangler.toml`, SPA-фолбэк в `_redirects`, заголовки безопасности в `_headers`).

## Друзья: подключение базы (один раз)

Подключает владелец проекта в Cloudflare:

```bash
npx wrangler login
npx wrangler d1 create casualhub
npx wrangler d1 execute casualhub --remote --file=schema.sql
```

Команда `create` выведет `database_id`. Его нужно вписать в `wrangler.toml`, заодно поправив имя проекта:

```toml
name = "casualhub"
pages_build_output_dir = "."
compatibility_date = "2024-01-01"

[[d1_databases]]
binding = "DB"
database_name = "casualhub"
database_id = "сюда id из команды create"
```

После пуша Cloudflare пересоберёт сайт. Проверка: `https://casualhub.pages.dev/api/health` должен ответить `{"ok":true}`.

## Резервные копии базы

Cloudflare сам хранит историю D1 (Time Travel) и может откатить базу на любой момент за последние 7 дней (на платном тарифе — 30):

```bash
npx wrangler d1 time-travel restore casualhub --timestamp=2026-10-26T12:00:00Z
```

Дополнительно GitHub Actions (`.github/workflows/d1-backup.yml`) каждый день выгружает базу целиком, шифрует и хранит 30 дней во вкладке Actions → D1 backup → Artifacts. Репозиторий публичный, поэтому без шифрования копию мог бы скачать кто угодно. Чтобы копии заработали, владелец репозитория добавляет в Settings → Secrets and variables → Actions три секрета:

- `CLOUDFLARE_API_TOKEN` — токен Cloudflare с правом **D1: Edit** (My Profile → API Tokens → Create Token → Custom);
- `CLOUDFLARE_ACCOUNT_ID` — id аккаунта (виден справа на главной странице Cloudflare Dashboard);
- `BACKUP_PASSPHRASE` — длинный пароль для шифрования. Сохрани его отдельно: без него копию не расшифровать.

Без секретов задача просто пропускается с предупреждением. Запустить вручную: Actions → D1 backup → Run workflow.

Восстановление из копии: выгрузка содержит `CREATE TABLE`, поэтому её заливают в новую пустую базу, а потом вписывают её `database_id` в `wrangler.toml`:

```bash
openssl enc -d -aes-256-cbc -pbkdf2 -iter 200000 -in casualhub-2026-10-26.sql.gz.enc -out dump.sql.gz
gunzip dump.sql.gz
npx wrangler d1 create casualhub-restore
npx wrangler d1 execute casualhub-restore --remote --file=dump.sql
```

## Защита входа

Сервер считает попытки в таблице `attempts`: не больше 10 неверных паролей в один аккаунт и 30 с одного адреса за 15 минут, не больше 10 регистраций (вместе с попытками на занятые почту или ник) с адреса в час, не больше 40 заявок в друзья за 10 минут. Сверх этого API отвечает `429` и пишет, сколько минут подождать.

## Запуск локально

Достаточно открыть `index.html` в браузере. Для полноценной работы (маршруты, `/koleso/`, друзья) удобнее запустить локальный сервер Cloudflare:

```bash
npx wrangler pages dev .
```

## Деплой

```bash
npx wrangler pages deploy .
```

> Оценки живут в браузере пользователя, друзьям уходит только копия. Чтобы не потерять оценки, периодически скачивайте резервную копию (JSON) из меню.
